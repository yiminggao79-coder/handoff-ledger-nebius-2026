# 实质问题与复用方法

## 托管执行边界阻止本机网络

现象：普通Node fetch本机HTTP产生EACCES；IAB首次访问本地服务超时。不是应用页面已验证失败或第三方API故障。依据：相同服务使用获准的本机执行后，IAB能够观察完整页面与来源展开。

处理：只将免费本地预览/HTTP验证放在可访问loopback的执行环境，不发布公网或下载新浏览器。HTTP smoke也需同样执行权限；普通边界失败保留为环境问题。适用：本机网络边界，不推广到所有网络故障。

## 引用存在不等于内容被支持

风险：系统可以验证N1存在，却不能据此断言真实根因。实现：拒绝未知/空引用，保留proposed状态、开放问题与显式人工语义复核。测试覆盖引用拒绝；未声称自动语义验证。复用：分别报告可机械检查的引用完整性与尚需人判断的支持关系。

## 公开live预算

评审指出冷却并不限制累计消耗。已增加小时/滚动日共享预算、单并发和正整数配置；3测试验证边界。适用仅当前进程和单实例，重启清零，不是云费用硬限额。仍须provider额度与评审可用性检查。

## 浏览器下载等待阻塞

点击导出后等待download事件未返回，约30分钟后被中断。未确认文件成功下载，不能写成通过。保留本地导出按钮与HTTP可序列化证据；真实浏览器下载体验仍待后续针对性验收。避免再用长时间无界事件等待阻塞交付。
